# کنترل خونه — اپ اندروید (Home Remote)

اپ بومی (Kotlin + Jetpack Compose) برای سرور `home-music-player` خودت؛ فقط یه مرورگر داخل اپ نیست.

## چی داره
- 🎵 **موزیک**: لیست و جستجو، پخش/مکث/بعدی/قبلی، شافل و تکرار، جابجایی زمان، صدای خونه، آپلود آهنگ از گوشی، **شنیدن همزمان** (پخش رو گوشی هم، هماهنگ با خونه)
- 📷 **دوربین**: وب‌کم زنده، **NVR کانال‌ها** (🛡 تشخیص آدم، 🎞 HD، ✨ بهبود کیفیت، ذخیره‌ی عکس تو گالری، تمام‌صفحه)
- 🛡 **امنیت**: بیرونم/رسیدم، مسلح کردن، واکنش خودکار، حساسیت، آژیر، همه‌ی گزینه‌ها، شبیه‌ساز حضور، حالت سرگرمی، خروج خودکار با وای‌فای، **رویدادها با عکس و ویدیو**، لاگ ورود
- 🖥 **دسکتاپ زنده** با موس و کیبورد (لمس مستقیم یا تاچ‌پد، راست‌کلیک، اسکرول، تایپ، کلیدهای میان‌بر)
- 🎤 **صحبت با خونه**، 👂 **گوش دادن به خونه**، 🔊 **صدای خود سیستم** (حتی با خاموش بودن صفحه)
- 🧰 وضعیت سیستم، قفل/خواب/ری‌استارت/خاموش، بلند بگو، کلیپ‌بورد، اجرای برنامه، اسکرین‌شات
- 📁 مدیریت فایل‌های سیستم (دانلود به گوشی و آپلود از گوشی)
- 🔔 **هشدار زنده**: وقتی آدم دیده شد اعلان گوشی با عکس (اختیاری)
- 👤 کاربر **«فقط‌تماشا»** (مثلا برای بابا) فقط دوربین‌های NVR رو میبینه و هیچ چیز دیگه‌ای نه

## امنیت
- ارتباط با سرور با **گواهی پین‌شده**: اولین بار اثر انگشت گواهی (SHA-256) رو نشونت میده تا با سرور مقایسه کنی و تایید کنی. بعدش فقط همون گواهی قبول میشه (جلوی حمله‌ی «مرد میانی» رو میگیره، حتی با گواهی خودامضا).
- رمز و کوکی نشست با **Android Keystore** رمزنگاری و ذخیره میشن. (اختیاری: نذار رمز ذخیره بشه.)
- قفل برنامه با اثر انگشت / قفل گوشی (تنظیمات ← امنیت اپ). روی اندروید ۱۰ و پایین‌تر این قفل غیرفعال میمونه.
- بکاپ‌گیری خودکار اندروید خاموشه (`allowBackup=false`).

## ساختن APK (یک بار)
1. **Android Studio** (نسخه‌ی Koala 2024.1 یا جدیدتر) رو نصب کن.
2. `File ← Open` و پوشه‌ی `HomeRemote` رو انتخاب کن؛ صبر کن Gradle همه‌چیز رو دانلود کنه (اینترنت لازمه؛ بار اول چند دقیقه).
3. `Build ← Build Bundle(s) / APK(s) ← Build APK(s)`.
4. فایل `app/build/outputs/apk/debug/app-debug.apk` رو رو گوشی نصب کن (نصب از منبع ناشناس رو اجازه بده).

اگه Android Studio پیشنهاد «Update Gradle / AGP» داد، قبولش کن.

## استفاده
- آدرس سرور: همونی که تو مرورگر میزنی (مثلا `192.168.1.100` و پورت `8080`). روی https بمون.
- نام کاربری و رمز خودت (یا کاربر فقط‌تماشا). اگه 2FA فعاله، کد رو بنویس.
- روی اولین اتصال اثر انگشت گواهی رو با پنجره‌ی سیاه سرور یا `certs/cert.pem` مقایسه کن.
- هشدار زنده: تنظیمات ← امنیت اپ ← «هشدار زنده». اپ باید باز نشده هم بمونه؛ مصرف باتری کمی داره.

## ساختار کد
`app/src/main/java/app/homeremote/`: `Net.kt` (اتصال امن، کوکی، API)، `Mjpeg.kt` (پخش زنده)، `AudioEngine.kt` (صدا)، `*Screen.kt` (صفحه‌ها)، `WatchService.kt` (هشدار زنده).
