# Home Music Player (Windroida)

پخش‌کننده‌ی موزیک خانه + کنترل از راه دور + امنیت خونه (دوربین/NVR، تشخیص آدم، شبیه‌ساز حضور انسان‌گونه، اپ اندروید).
Home music player with remote control, home security (webcam / NVR people detection), a human-like presence simulator and an Android app.

📖 فهرست کامل قابلیت‌ها: [docs/FEATURES.fa.md](docs/FEATURES.fa.md)

## نصب سریع (ویندوز)
1. پروژه رو دانلود کن (Code ← Download ZIP) و از حالت زیپ دربیار.
2. آهنگ‌ها رو بریز تو پوشه‌ی `music/` (و اگه خواستی صدای خونه مثل سرفه، ظرف، تلویزیون، پارس سگ تو `sounds/`).
3. روی `start.bat` دوبار کلیک کن. پایتون و پکیج‌ها رو خودش نصب میکنه.
4. اولین اجرا یه **رمز تصادفی** میسازه و **فقط یک بار** تو پنجره نشونت میده؛ همون‌جا بنویسش. یوزر پیش‌فرض: `admin`.
5. تو مرورگر (یا اپ) برو `https://IP-کامپیوتر:8080` (گواهی خودساخته‌ست؛ هشدار مرورگر عادیه).

## 🔐 کاربرها و رمزها (کامل)
تو این برنامه ۴ جور یوزر/رمز جدا هست؛ قاطیشون نکن:

| # | چی | یوزر / رمز پیش‌فرض | کجا عوض میشه |
|---|---|---|---|
| 1 | **ورود به پلیر** (ادمین، همه‌چیز) | یوزر `admin`، رمز تصادفی اولین اجرا | پایین‌تر |
| 2 | **کاربر بیننده** (فقط دوربین‌های NVR) | ندارد؛ خودت میسازی | پایین‌تر |
| 3 | **NVR** (خود دستگاه دوربین) | `admin` / `admin` (نمونه؛ حتما عوض کن) | `start.bat` |
| 4 | **ویندوز** (فقط اگه ورود خودکار بخوای) | رمز ویندوز خودت | `autologin-on.bat` |

### 1) ورود به پلیر (ادمین)
- **یوزر:** پیش‌فرض `admin`. عوض کردن: تو `start.bat` خط `set PLAYER_USER=اسم-تو` رو از حالت `rem` دربیار (فقط حروف و عدد). بعدش برنامه رو ببند و دوباره `start.bat` بزن.
- **رمز اولین اجرا:** خودش یه رمز تصادفی میسازه و **فقط همون یک بار** تو پنجره‌ی سیاه نشون میده (هش‌شده تو `password.hash` ذخیره میشه، خود رمز نه). همون لحظه بنویسش.
- **عوض کردن رمز یا فراموشی:** `set-password.bat` رو بزن، رمز جدید (حداقل ۱۰ حرف) رو دو بار بنویس، بعد برنامه رو دوباره اجرا کن. همه‌ی نشست‌های قبلی (گوشی‌ها و مرورگرها) بسته میشن و باید دوباره وارد بشن.
- **رمز ثابت تو فایل:** اگه تو `start.bat` خط `set PLAYER_PASSWORD=...` رو فعال کنی، همون رمز استفاده میشه و روی `set-password.bat` و `password.hash` اولویت داره. پس اگه `set-password.bat` اثر نمیکنه، این خط رو چک کن. رمزش رو هیچ‌وقت تو گیت‌هاب نذار.
- **امنیت:** بعد از ۵ رمز غلط قفل میشه (۱، ۲، ۴ ... تا ۶۰ دقیقه). `🔒 خروج همه‌ی دستگاه‌ها` تو صفحه، یا `/logout_all` تو تلگرام، همه‌ی نشست‌ها رو میبنده (مثلا وقتی گوشیت گم شد).
- **ورود دو مرحله‌ای (اختیاری):** `setup-2fa.bat` رو یک بار اجرا کن و QR رو تو Google Authenticator اسکن کن؛ از اون به بعد فقط ورود از بیرون خونه کد هم میخواد.

### 2) کاربر بیننده (مثلا برای یه عضو خانواده که فقط دوربین‌ها رو ببینه)
اون فقط NVR رو میبینه، به موزیک، دسکتاپ، فایل‌ها و تنظیمات دسترسی نداره.
- **ساختن یا عوض کردن رمز:** `add-viewer.bat` ← یوزر (حروف کوچیک انگلیسی/عدد/`_ . -`، ۲ تا ۳۲ حرف، نباید با یوزر ادمین یکی باشه) ← رمز (حداقل ۸ حرف) دو بار. اگه یوزر از قبل هست، رمزش عوض میشه و نشست‌های قبلیش بسته میشن.
- **لیست کاربرها:** `list-viewers.bat`
- **حذف:** `remove-viewer.bat` ← اسم یوزر. نشست‌هاش همون لحظه کار نمیکنه.
- رمز بیننده‌ها هش‌شده تو `viewers.json` کنار برنامه میمونه؛ این فایل تو `.gitignore` هست و آپلود نمیشه. رمز رو نمیشه از روی فایل خوند؛ فراموش شد، دوباره `add-viewer.bat` با رمز جدید.

### 3) یوزر و رمز NVR
مثل بخش «وصل کردن NVR» پایین: `NVR_USER` و `NVR_PASS` تو `start.bat`. این‌ها یوزر/رمزِ خودِ دستگاه دوربینه، نه ورود به پلیر. اگه رمز NVR رو تو خود دستگاه عوض کردی، اینجا هم باید عوضش کنی.

### 4) ورود خودکار ویندوز (اختیاری)
`autologin-on.bat` بعد از ریستارت خودش وارد ویندوز میشه، ولی **رمز ویندوز رو تو رجیستری به‌صورت متن ساده** نگه میداره؛ فقط برای کامپیوتر خونه. غیرفعال کردن: `autologin-off.bat`.

### قبل از اینکه کد رو به کسی بدی (چک‌لیست)
- [ ] تو `start.bat` فقط مقدارهای نمونه هست (`admin` / `admin` برای NVR)، نه رمز واقعی.
- [ ] `password.hash`، `viewers.json`، `settings.json`، `telegram-alerts.bat` بیرون از گیت (تو `.gitignore` هستن).
- [ ] رمزی که یه بار تو گیت یا چت یا اسکرین‌شات رفته رو عوض کن.

## 📹 وصل کردن NVR (دوربین‌ها)
تو `start.bat` این ۳ خط رو با مشخصات NVR خودت عوض کن:
```bat
set "NVR_IP=192.168.1.10"     rem آی‌پی NVR تو شبکه‌ی خونه (از منوی شبکه‌ی خود NVR یا لیست دستگاه‌های روتر)
set "NVR_USER=admin"          rem یوزر NVR (پیش‌فرض خیلی از NVRها: admin)
set "NVR_PASS=admin"          rem رمز NVR (حتما عوضش کن؛ خود NVR باید رمز قوی داشته باشه)
```
- علامت‌هایی مثل `@ % & ^` تو رمز عادیه؛ فقط خط رو **با گیومه** بنویس (همون‌طور که بالا هست). `%` رو باید `%%` بنویسی.
- کانال‌ها: `set NVR_CHANNELS=1,2` (هر چندتا که داری، مثلا `1,2,3,4`).
- آدرس RTSP رو خودش پیدا میکنه. اگه پیدا نکرد، آدرس کامل رو بده: `set CAMERA_URL=rtsp://user:pass@IP:554/...`، یا پورت RTSP رو عوض کن: `set NVR_RTSP_PORT=554`.
- **تست:** یه بار `start.bat` رو اجرا کن (برای نصب)، بعد `nvr-test.bat` رو بزن؛ برای هر کانال میگه وصل شد یا نه و عکس تست میگیره.
- اگه «یوزر/رمز قبول نشد» اومد: بعد از ۳ بار امتحان خودش میایسته تا NVR قفلت نکنه. یوزر/رمز رو درست کن و برنامه رو دوباره اجرا کن.
- **با مسلح شدن** (دکمه یا `/arm` تلگرام) به NVR وصل میشه و تشخیص آدم همه‌ی کانال‌ها روشن میشه؛ اگه تا ۳۰ ثانیه وصل نشه اعلان میده. خاموش کردنش: `set NVR_WITH_ARM=0`.
- فقط از وب‌کم همین کامپیوتر استفاده میکنی؟ همون ۴ خط `NVR_*` رو پاک کن.

## اعلان روی گوشی (اختیاری)
- ساده‌ترین: اپ **ntfy** رو نصب کن و تو `start.bat` بذار `set NTFY_TOPIC=یه-اسم-طولانی-و-تصادفی`.
- ربات تلگرام/بله: فایل `telegram-alerts.example.bat` رو کپی کن به `telegram-alerts.bat` و توکن و chat id خودت رو بذار (این فایل تو `.gitignore` هست و آپلود نمیشه).

## اپ اندروید
پوشه‌ی `android/HomeRemote` (راهنمای ساخت: `android/HomeRemote/README.md`). تو اپ آدرس `IP:8080` و یوزر/رمز بالا رو بزن.

## ⚠️ قبل از آپلود تو گیت‌هاب
`.gitignore` این‌ها رو آپلود نمیکنه: `password.hash`, `.secret_key`, `settings.json`, `certs/`, `captures/`, `viewers.json`, `telegram-alerts.bat`, آهنگ‌ها و صداهای شخصی. با این حال قبل از push یه بار `git status` رو نگاه کن و مطمئن شو چیز شخصی تو لیست نیست. اگه قبلا رمز واقعیت (مثلا رمز NVR) تو یه نسخه‌ی قدیمی گیت رفته، رمز رو عوض کن؛ پاک کردن از تاریخچه کافی نیست.
